# US-006 — Secret scanning in CI

_Generated by this story's proving commands · 2026-08-06 · PASS_

## 1. ci.yml's required check job runs gitleaks against every PR

```console
$ grep -A8 'Secret scan (gitleaks)' .github/workflows/ci.yml
      - name: Secret scan (gitleaks)
        env:
          GITLEAKS_VERSION: 8.30.1
        run: |
          set -euo pipefail
          mkdir -p "$RUNNER_TEMP/gitleaks"
          curl -sSfL "https://github.com/gitleaks/gitleaks/releases/download/v${GITLEAKS_VERSION}/gitleaks_${GITLEAKS_VERSION}_linux_x64.tar.gz" \
            | tar -xz -C "$RUNNER_TEMP/gitleaks" gitleaks
          "$RUNNER_TEMP/gitleaks/gitleaks" detect --source . --config .gitleaks.toml --redact --no-banner --no-color
```
