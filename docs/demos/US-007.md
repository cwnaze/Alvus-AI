## 1. Every PR gets a Cloudflare Workers preview: deploy-preview.yml uploads a per-PR Worker Version (never production traffic, never the Worker's bound secrets) using only the Cloudflare deploy-time credential, then posts the alias URL back to the PR

```console
$ grep -B2 -A12 'Upload preview version' .github/workflows/deploy-preview.yml
        run: npm install

      - name: Upload preview version
        id: preview
        # Only the Cloudflare deploy-time credential -- no DB/Stripe/LiteLLM
        # secret is loaded into this job, so a preview can never touch
        # production data even by accident. Worker secrets already bound to
        # the Worker (see deploy.yml) still apply to this version; nothing
        # here sets or changes them.
        env:
          CLOUDFLARE_API_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}
          CLOUDFLARE_ACCOUNT_ID: ${{ secrets.CLOUDFLARE_ACCOUNT_ID }}
        run: |
          set -euo pipefail
          alias="pr-${{ github.event.pull_request.number }}"
```

```console
          set -euo pipefail
          set -a
          source .env
          set +a
          # drizzle-kit owns the app schema (users/waitlist_signups/tier_limits/...);
          # supabase db push owns the Supabase-specific surface drizzle doesn't
          # (RLS policies, Storage bucket config, Auth settings). Neither is atomic
          # with the deploy below -- see docs/infra.md's rollback plan for why
          # migrations default to additive/backward-compatible.
          npx drizzle-kit migrate
          # No SUPABASE_DB_PASSWORD secret exists to drive a non-interactive
          # `supabase link`, so this pushes straight at DATABASE_URL instead --
          # equivalent result, one fewer credential to provision.
          npx supabase db push --db-url "$DATABASE_URL" --yes

      - name: Deploy to Cloudflare Workers
        run: npm run deploy

      - name: Bind app-runtime secrets to the Worker
```

## 8. Every app-runtime variable (.env.example's 'App runtime' section) is bound to the Worker via wrangler secret put, sourced from the same repo secrets

```console
/**
```
